## Setup

1. Navigate to the backend folder.
2. Create and activate a virtual environment.
3. Install dependencies:
   ```bash
   pip install django
   ```
4. Run migrations and start the server:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
